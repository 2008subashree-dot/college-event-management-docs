# College Event Management System

## Introduction

The College Event Management System is a web-based application used to manage college events and registrations.

## Features

- Student registration
- Event creation
- View upcoming events
- Event registration
- Manage participant details

## Technologies Used

- HTML
- CSS
- JavaScript

## Installation

1. Download the project.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Usage

1. Open the College Event Management System.
2. View the available events.
3. Select an event.
4. Register for the event.
5. View the registration details.
